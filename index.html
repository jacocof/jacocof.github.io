OAK Drive Verifier checks that selected OAK transcript exports have reached the owner's Google Drive before OAK compresses their original audio on the owner's Windows computer.

What the desktop tool does

  1. Reads the metadata and actual text of a managed transcript in the configured private Drive folder.
  2. Compares the cloud text with the current local export and its source records.
  3. Records verification locally. OAK then permits lossless local audio compression only when its existing evidence checks pass.

The desktop worker runs every 15 minutes while Windows is signed in, awake, and online. Google Drive for desktop handles the separately configured text uploads.

Read-only Google access

Google's drive.readonly permission allows account-wide reading. The verifier limits its normal work to pending OAK transcript filenames in the selected folder; an explicitly selected managed file may also be checked during setup. It requests no permission to edit, delete, or share Drive files.

Google authorization happens in Google's browser flow on the Windows computer. This information website does not sign users in, collect recordings, receive credentials, or run the verifier.

Personal use

This is a privately operated tool for its owner's account, not a public transcription service. Audio stays on the desktop; the verifier does not upload it. There is no subscription or payment collection on this site.
