Privacy notice

This notice covers the personal OAK Drive Verifier desktop component and its information website.

Google data accessed and its purpose

The desktop verifier uses Google's drive.readonly scope. Google grants account-wide read access, but normal verification searches only for exact pending OAK transcript filenames in the owner's selected Drive folder. Setup can also check an explicitly selected managed transcript.

It reads folder/file metadata and transcript text to confirm the cloud copy matches the current local export. Metadata can include file identifiers, parent folders, names, media types, sizes, versions, timestamps, and checksums. This check protects against compressing local audio before a corresponding text export is verified.

Processing, storage, and retention

Drive text is downloaded to memory on the owner's Windows computer and compared locally. The verifier does not duplicate that cloud text into run receipts. OAK keeps its existing local transcripts, source evidence, checksums, and verification ledger in its private local store. Verification metadata persists with that store; the latest 200 desktop run receipts are retained.

The refresh grant and OAuth client details are stored in the current Windows user's Credential Manager. Access tokens remain in memory. A locally downloaded client-configuration file may also remain until the owner removes it.

Original audio stays local. OAK permits lossless compression only after its source and Drive verification checks pass. Missing transcripts, mismatches, or unavailable authorization preserve the originals.

Sharing and limited use

The verifier communicates with Google's OAuth and Drive services to perform the authorized check. It does not send Drive transcript contents to this website, its hosting provider, advertising services, or AI providers. It does not sell Google user data, use it for advertising, or use it to train models.

OAK Drive Verifier's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Separately configured OAK transcript exports and other OAK features are controlled by the owner and are outside this verifier's read-only Google grant.

Your controls and deletion

The owner can stop the desktop task, disconnect its local grant with OAK's omi native-drive-disconnect command, and revoke OAK Drive Verifier in Google Account connections. Disconnecting does not delete transcripts, verification evidence, or Drive files.

The owner controls deletion of local OAK records, audio archives, and downloaded client files, and can separately delete Drive exports through Google Drive. The verifier has no Drive deletion permission. Contact redoakval@gmail.com for questions about this personal tool.

Information website

These static pages contain no forms, sign-in flow, analytics scripts, or advertising. When hosted on GitHub Pages, GitHub logs visitors' IP addresses for security purposes, as explained in GitHub's Pages documentation and its privacy statement. The website receives no Google OAuth grant or transcript data.
